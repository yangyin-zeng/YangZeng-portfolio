CDC Data Processing Exercise

Influenza Vaccination Coverage

Author

Yang Zeng

Research question

How does influenza vaccination coverage vary across age groups, geography, and flu seasons?

Data processing

The processing script imports the CDC data, converts unreported values to missing values, parses confidence intervals, validates numeric ranges, and creates comparable national and state subsets.
